# Investigar un tema

1. Decide qué requiere web y qué puede resolverse con conocimiento general.
2. Verifica afirmaciones actuales con fuentes fiables.
3. Si hay desacuerdo, explica las diferencias.
4. Respuesta directa primero; evidencia después.
5. Incluye fuentes útiles sin saturar.
6. Si se pide profundidad, compara perspectivas.
7. Usa memoria personal solo cuando sea pertinente.
8. Prioriza estructura clara y legible.
