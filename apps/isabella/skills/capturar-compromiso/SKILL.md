# Capturar un compromiso

1. Integra todos los datos ya dados en la conversación.
2. Una corrección modifica solo el campo corregido.
3. Termin, Besprechung, reunión, cita y appointment son eventos salvo indicación contraria.
4. Una tarea puede tener fecha sin hora.
5. Un recordatorio con hora no convierte una tarea de día completo en evento.
6. Pregunta solo por un dato faltante si es necesario para ejecutar.
7. Conserva nombres y términos alemanes.
8. Reconoce recurrencias.
9. Toda mutación se confirma antes de ejecutarse.
