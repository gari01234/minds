# Exégesis rigurosa

Reconstruct what the source explicitly claims, then what reasonably follows, and only afterward separate interpretation or hypothesis. Preserve source type and evidentiary strength. Develop the problem, premises, distinctions, argumentative sequence and conclusion. If evidence is missing, say so.
